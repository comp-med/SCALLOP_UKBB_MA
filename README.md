**Multi-cohort proteogenomic analyses reveal genetic effects across the proteome and diseasome**

This repository contains code associated with the study "Multi-cohort proteogenomic analyses reveal genetic effects across the proteome and diseasome" ([DOI](https://doi.org/10.1016/j.cell.2026.03.049)).  The provided scripts are not designed to work out of the box, but rather illustrate the main steps done for each of the analysis performed.
